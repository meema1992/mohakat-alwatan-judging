# منصة تحكيم محاكاة الوطن تجمعنا

## الملفات
- `index.html`, `styles.css`, `app.js`: واجهة عربية متجاوبة.
- `firebase-config.example.js`: قالب إعداد Firebase. انسخيه باسم `firebase-config.js` وضعي بيانات مشروعك.
- `firestore.rules`: قواعد تمنع الكتابة المباشرة إلى التقييمات والنتائج.
- `functions/`: وظائف آمنة لإنشاء دخول المحكّمين والتحقق منهم وحفظ التقييمات وتجميع النتائج.

## احتساب الدرجات المعتمد
- 4 محاور × 4 معايير × 6 درجات = 96 درجة خام لكل محكّم.
- الدرجة المحوّلة = (مجموع المحكّم ÷ 96) × 100.
- النتيجة النهائية = متوسط الدرجات المحوّلة للمحكّمين الذين أرسلوا تقييماتهم.
- تعديل المحكّم لتقييمه يستبدل تقييمه السابق، فلا يتكرر احتسابه.

## متطلبات الربط قبل التشغيل الفعلي
1. أنشئي مشروع Firebase، وفعّلي Authentication (Email/Password) وFirestore.
2. أنشئي حساب الإدارة في Firebase Authentication، ثم أنشئي يدويًا مستندًا في `users/{UID}` يحتوي `{ "role": "admin" }`.
3. انسخي `firebase-config.example.js` إلى `firebase-config.js` واملئي إعدادات Web App. لا ترفعي `firebase-config.js` إلى مستودع عام إذا رغبتِ بإبقائه خارج المستودع؛ أضيفيه إلى `.gitignore`.
4. انشري قواعد `firestore.rules` وانشري Cloud Functions من مجلد المشروع باستخدام Firebase CLI.
5. بعد النشر، افتحي GitHub Pages. لن يعمل الدخول والحفظ قبل إكمال هذه الخطوات.

## تنبيه
هذه نسخة تأسيسية قابلة للتطوير. لا تضعي كلمات مرور أو رموز محكّمين في ملفات HTML/JS. إنشاء المحكّمين يتم عبر وظيفة موثوقة وتخزين رمز الدخول على هيئة hash.
