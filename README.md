# منصة تحكيم محاكاة الوطن تجمعنا — نسخة الرمز الموحد

## دخول اللجنة
- رمز دخول موحد: `WATAN2034` (يمكن تغييره في `app.js` من قيمة `SHARED_JUDGE_CODE`).
- يسجل عضو اللجنة دخوله بتسجيل Firebase مجهول (Anonymous).
- كل إرسال تقييم يُسجل كسجل مستقل؛ تكرار الإرسال سيزيد عدد التقييمات.
- لوحة النتائج تحسب المتوسط وعدد التقييمات تلقائيًا مباشرة من Firestore.

## الإدارة
- دخول الإدارة يبقى بالبريد وكلمة المرور الحاليين.
- يجب وجود `users/{UID}` وفيه `role: "admin"`.
- الإدارة وحدها تستطيع إضافة المشاركين وتعديلهم.

## إعداد Firebase المطلوب
1. في Authentication > Sign-in method فعّلي **Anonymous** إضافة إلى Email/Password.
2. انشري محتوى `firestore.rules` في Firestore > Rules ثم اضغطي Publish.
3. تأكدي أن `firebase-config.js` موجود في جذر الموقع ويحتوي `window.FIREBASE_CONFIG = { ... }`.
4. ارفعي ملفات النسخة المعدلة إلى GitHub Pages.

## ملاحظات مهمة
- هذه النسخة لا تستخدم Cloud Functions ولا تتطلب ترقية Blaze.
- الرمز المشترك بوابة تنظيمية فقط وليس سرًا قويًا؛ من يعرفه يمكنه إرسال تقييمات متعددة، وهذا يتوافق مع قرار اللجنة بالاعتماد على الأمانة.
- التقييمات للقراءة العامة حتى يمكن حساب لوحة النتائج دون خادم مدفوع. لا تخزّن في التقييمات أي معلومات شخصية.
- أرقام التقييمات تمثل عدد مرات الإرسال، وليس عدد الأشخاص الفريدين.
